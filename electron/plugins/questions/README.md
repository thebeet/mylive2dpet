# 通用补充提问

`questions` 展示记忆模型根据实际交流产生的问题，适用于各种生活场景，不预设人物画像字段。需同时启用 `questions.enabled` 和 `memory.questions.enabled`；`memory.work` 服务名保留兼容，但已经提供通用问题与回答接口。

```json
{
  "name": "questions", "enabled": true, "auto": true,
  "dailyLimit": 3, "cooldownMs": 1800000, "deferMs": 1800000,
  "minIdleSeconds": 8, "maxIdleSeconds": 300, "maxSkips": 3,
  "pollMs": 15000, "timeoutMs": 90000
}
```

模型只有在问题对后续陪伴有帮助时才生成候选，支持2至4个选项和自由回答。回答作为明确用户来源进入统一记忆维护，不直接写入固定画像字段。可关闭记忆侧问题生成，不影响其他记忆能力。

自动浮窗仅在闲置区间、无在途决策或TTS、近期音频静默时出现，不抢焦点。`dailyLimit` 与 `cooldownMs` 控制新窗口频率，0表示不设限制。未操作窗口到期延后，获得焦点或开始输入后取消超时；已打开窗口不会因为新的决策或语音突然关闭。

手动打开绕过自动时机限制，仍尊重问题延后时间。反复跳过达到 `maxSkips` 后停止询问；「稍后再问」不增加跳过次数。移除问题删除其记录，并阻止同一题目自动重建。

「记忆 → 查看提问记录」可查看并删除问题、回答与展示记录。删除记录不会撤销已经形成的记忆，若需忘记对应内容，应使用记忆页的忘记操作。清空全部记忆时一并清除问题记录。

来源与记忆意愿规则见 [记忆插件](../memory/README.md)。
